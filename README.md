👨‍💻 About Me

Hey! I'm Rishi, a frontend developer behind Tech Show.

I enjoy building modern, interactive, and visually engaging web experiences with clean interfaces and meaningful animations.

I believe great frontend development is more than making things look good. It's about combining design, functionality, performance, and user experience.

- 🚀 Developing with React.js and Next.js
- 🎬 Creating interactive animations with GSAP
- 🎨 Interested in UI/UX, Minimalism, and Neumorphism
- 🧩 Exploring creative frontend interactions
- 📚 Constantly learning new technologies
- 💡 Turning ideas into functional web experiences
