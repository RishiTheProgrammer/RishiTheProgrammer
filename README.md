## About

Hey, I'm Rishi. I build modern frontend interfaces with **Next.js**, **React**, **GSAP**, and **Bootstrap**.

I care about clean layout, responsive grids, and motion that helps the page instead of getting in the way. Right now I'm also learning **Python**, **Three.js**, and **Spline** so I can add more interactive and 3D work later.

- Building with Next.js, React, HTML, CSS, JavaScript, GSAP, and Bootstrap
- Exploring 3D with Three.js and Spline
- Learning Python fundamentals
- Open to frontend practice, UI polish, and small collaborations
